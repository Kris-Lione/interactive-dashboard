## Imperial/Metric Converter
A mathematical conversion tool to convert values between the imperial and metric system,
by using multiplication and allowing user selection and inputs. 
Asks user for their input and conversion type.

## Logic and Pseudocode
Ask user to input 1 for imperial to metric or 2 for metric to imperial. If the user selects one ask them to input their number and select either inches, feet, yard, or miles. If they select inches multiply their number by 2.54 and output their new number with centimeters. If they select feet multiply their number by 30.48 and output their new number with centimeters. If they select yard multiply their number by 0.91 and output their new number with meters. If they select miles multiply their number by 1.61 and output their new number with kilometer. If the user selected 2 for metric to imperial then ask them for their number and have them select centimeter to inch, centimeter to foot, meter to yard, or kilometer to mile. If they select centimeter to inch multiply their number by 0.39 and output their new number with inch. If they select centimeter to foot multiply their number by 0.0328 and output their new number with foot. If they select meter to yard multiply their number by 1.09 and output their new number with yard. If they select kilometer to mile multiply their number by 0.62 and output their new number with mile.
